# Advanced Python & Machine Learning — End-of-Chapter Exercises

This repository contains the practice exercises and sample solutions that accompany **Python Programming Fundamentals: A Comprehensive Guide** by Bernard Baah (Filly Coder).

## 📂 Files in this repo

| File | Description |
|------|-------------|
| `End_of_Chapter_Exercises.docx` | End-of-chapter exercises for each chapter of the book. Work through these to reinforce what you have learned. |
| `Sample_Solutions_to_End_of_Chapter_Exercises.docx` | Sample solutions to the exercises. Review these after you have attempted the problems yourself. |

## 🎯 How to use these files

1. Read the relevant chapter in the book.
2. Open `End_of_Chapter_Exercises.docx` and attempt the exercises for that chapter.
3. Check your work against `Sample_Solutions_to_End_of_Chapter_Exercises.docx`.
4. If a solution differs from yours, revisit the chapter explanation to understand why.

> **Tip:** Try every exercise on your own before looking at the solutions — the struggle is where the learning happens.
